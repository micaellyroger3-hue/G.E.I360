# Homologação no aparelho — G.E.I360

Este roteiro é para o aparelho Android do usuário, sem enviar senhas, códigos de autenticação ou chaves.

## Instalação PWA
1. Abra o endereço HTTPS do G.E.I360 no Chrome.
2. Atualize a página depois da publicação da versão do service worker.
3. No menu do Chrome, escolha instalar/adicionar à tela inicial.
4. Abra pelo ícone instalado e confirme que a tela abre sem a barra do navegador.

## Offline e cache
1. Com o app aberto e conectado, navegue por Visão geral e Operação do ramo para aquecer o shell.
2. Ative o modo avião e feche/abra o app pelo ícone.
3. Confirme que a tela offline aparece sem tentar carregar módulos protegidos.
4. Desative o modo avião, aguarde a reconexão e confirme que a sessão retorna.

## Scanner
1. Abra Produtos e toque em Ler código.
2. Permita a câmera somente quando o Chrome solicitar.
3. Aponte a câmera traseira para um código EAN-13 ou Code 128.
4. Confirme que o código preenche o campo e que a câmera desliga após a leitura.
5. Coloque o app em segundo plano durante a leitura; a câmera deve desligar.
6. Se o navegador não oferecer BarcodeDetector, use digitação ou leitor USB/Bluetooth.

## Documentos
1. Como proprietário/administrador/gerente, abra Documentos e envie um PDF pequeno de teste.
2. Baixe/abra o mesmo arquivo e confirme que o conteúdo é o mesmo.
3. Entre com perfil funcionário e confirme que a lista/arquivo empresarial não fica acessível.
4. Não use documentos reais de clientes na primeira rodada; use arquivo de teste sem dados pessoais.

## Resultado
Anote somente: instalação OK/erro, offline OK/erro, scanner OK/erro, upload OK/erro e download OK/erro. Não envie arquivos privados nem credenciais no chat.
